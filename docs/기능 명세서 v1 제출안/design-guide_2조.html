동작 규칙

  • 준비 완료 체크와 삭제 선택은 상태가 분리됩니다. 선택 모드를 끝내도 기존 체크 상태는 유지
  • 기본 정렬은 미체크 아이템 우선
  • 편집 모드에서 연필 클릭 → 이름 변경 다이얼로그, X 클릭 → 즉시 삭제 + 되돌리기 토스트 (5.13 참고)
  • 삭제 선택 모드에서도 연필·X는 그대로 동작. 체크박스는 여러 아이템을 모아 하단 액션바로 한 번에 삭제할 때만 사용
  • “아이템 추가” 텍스트를 누르면 같은 자리(항목 목록 맨 아래)가 입력 필드로 바뀌고 자동 포커스
  • 글자 수 제한 — 30자를 넘겨도 입력은 자유롭게 허용합니다. 30자 초과 시 +가 Text 3(회색)로 바뀌며 클릭이 막히고, 클릭을 시도하면 “최대 30자까지 입력할 수 있어요” 토스트가 뜹니다. 미입력 상태의 +는 Primary 그대로이고 클릭만 막힙니다
  • + 클릭, Enter, 모바일 키보드 “다음”으로 추가. 추가되면 새로 생긴 “아이템 추가” 행의 입력 필드로 포커스 자동 이동
  • 카테고리 내 모든 아이템이 삭제되면 “아이템 추가” 행만 남습니다

C-03과의 관계

C-03은 이 면책 조항 컴포넌트를 확인하기 위한 별도 화면 설계서 항목이며, 실제로는 새 화면이 아니라 C-01 최하단에 포함된 섹션입니다. 별도 라우팅이나 진입 동선이 없습니다.

10접근성

  • 터치 타겟 — 최소 44×44px. 리스트 행 48px, 메뉴 항목 44px, 버튼 56px은 충족. 미트볼·닫기·달력 화살표는 투명 패딩으로 확장
  • 명도대비 — Text 3(50%)는 흰 배경에서 약 4.6:1로 본문 통과. Line(25%)은 텍스트로 쓰지 않고 보더·비활성 아이콘 전용
  • Primary 위 흰 텍스트 — 약 3.1:1. CTA(20px/600)는 통과, 칩·달력의 14px 흰 텍스트는 기준 미달
  • 삭제 선택 모드 — 체크박스 색만 바뀌므로 액션바의 “{N}개 선택됨”이 보조 신호로 항상 함께 노출되어야 합니다
  • 동적 텍스트 — 폰트 확대에도 레이아웃이 깨지지 않게 고정 높이 대신 최소 높이로 설계
