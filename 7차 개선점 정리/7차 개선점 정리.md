- **CHG-089**
    - A-03 활동을 선택하지 않아도 체크리스트 생성 가능 (활동은 필수가 아님)
- **CHG-090**
    - C-01 본래 존재하던 케밥 위치의 왼쪽에 필터 아이콘, 케밥 위치에는 편집 아이콘으로 변경.
    - 필터 아이콘은 클릭 시 미체크 아이템 모아보기, 찜한 아이템 모아보기 메뉴 노출
        - 미체크 아이템 모아보기 클릭: 체크된 아이템 숨김처리 및 접힌 카테고리 모두 펼치기. 체크된 항목이 있는 카테고리가 상단에 위치하도록 정렬
        - 찜한 상품 모아보기 클릭: 찜이 되지 않은 아이템 숨김처리 및 접힌 카테고리 모두 펼치기. 찜한 항목이 있는 카테고리가 상단에 위치하도록 정렬
        - 두 모아보기 활성화 시 ‘전체 아이템 보기’ 로 토글되어 클릭 시 아이템 숨김 해제, 이 때 ‘전체 아이템 보기’ 버튼은 하나만 표시
    - 편집 아이콘 클릭 시 F-01 카테고리, 아이템 편집 가능 상태로 변경
- **CHG-093**
    - C-01 준비물 삭제 안내 바텀 시트 추가
    - 디자인 상세는 피그마 C-04 화면의 2번 항목 참조
    - 이미지 하단의 bottom_sheet_img.svg 파일 사용

- **CHG-091**
    - E-01 편집 모드 내에서도 CHG-090에서 추가된 필터 아이콘 표시. 동작도 동일.
- **CHG-092**
    - E-01 이미 C-01의 기본 상태에서 체크된 항목들은 편집 모드 내에서 체크 불가. 체크박스 #3A3A3A 투명도 20% fill로 변경, stroke 없음. #ffffff 체크 아이콘.
- **CHG-094**
    - 다른 활동을 추가해달라는 UT 결과가 있어 활동 추가를 직접 할 수 있도록 수정이 필요합니다. (ex. 먹방, 호캉스, 관광지, 공연·예술 등 활동 추가 요청)
    - 활동 카테고리(activity)도 Supabase DB를 통해 관리할 수 있도록 DB 테이블 추가
        - DB에서 사용하는 activity_id, A-03 페이지의 활동 선택 위젯에 보일 activity_name, C-01 이후의 체크리스트 페이지 및 카테고리 추가 페이지에서 표시될 activity_category_name 컬럼
        - 해당 테이블에 새 row를 추가하여 새로운 활동을 추가할 수 있어야 함
        - 체크리스트 생성 정보 입력 시 활동 목록, 체크리스트 카테고리 및 카테고리 추가 기능은 해당 테이블 내용을 토대로 표시되어야 함.
        - 활동이 선택된 상태로 생성하는 경우 활동에 연결된 준비물(아이템)이 없어도 체크리스트에 활동에 해당하는 카테고리가 포함된 상태로 생성되어야 함
- **CHG-088**
    - 아이템 정렬 순서를 추가하는 이유는 기존 아이템이 표시되는 순서에 맥락이 없어 사용자가 불편하다는 UT 결과를 근거로 합니다. (ex. 멀티탭·변압기가 함께 있지 않고 따로 있다)
    - 수정 방안
        1. catalog_items 테이블에 item_group 컬럼과 item_order 컬럼을 추가(group은 category 와는 별도로 의복, 위생(세안)용품, 전기(충전)용품 등을 구분에 따라 모아서 표시하기 위한 개념)
            1. item_group 에는 cloth, wash, electric 등 물품의 구분명 입력 가능. 각 그룹은 (2) 항목의 catalog_group 테이블 내 순서에 따라 리스트에 표시되어야 함. group 명이 null 인 경우 가장 마지막에 표시
            2. item_order 컬럼은 (a) 항목의 item_group 안에서의 표시 우선순위(순서)를 의미. 숫자가 작을수록 먼저(위에) 표시. 우선순위(순서)가 같은 경우의 순서는 신경쓰지 않으며 기존 순서를 따름
        2. catalog_group 테이블을 추가
            1. catalog_group 내에 추가되어야 하는 내용
                
                (1.a) 항목의 item_group 간 리스트 표시 순서를 지정할 수 있어야 함
                
        - 예시)
