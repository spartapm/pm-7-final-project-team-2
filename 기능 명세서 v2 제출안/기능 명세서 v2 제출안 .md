## 1. 기능 명세 정의

> **Must Have**: 반드시 구현 / **Nice to Have**: 추가 기능 / **Out of Scope**: 이번 버전에서 제외
> 

| 우선순위 | 기능명 | 설명 |
| --- | --- | --- |
| Must Have | 트리플에 작성한 일정을 토대로 준비물 체크리스트 생성 | • 어디로(국가), 언제(기간), 누구와(혼자, 부모님과, 연인(배우자)과, 아이와, 반려동물과 등), 어떤 여행(수영, 하이킹, 해변, 동계 스포츠, 캠핑, 사진 등)을 하는지 입력 받기
• 입력 받은 정보 기반 기본 리스트 출력(카테고리 기준 수립) |
| Must Have | 체크리스트 항목별 소지 여부 체크 | 생성·편집된 항목에 대해 가지고 있는지/없는지 체크 |
| Must Have | 체크리스트 항목에 대해 구매할 물건 체크 | • 구매할 물건에 대해 상품을 찜하는 기능 |
| Must Have | 체크항목 리스트 정렬 기능 | • 체크 항목 / 미체크 항목 정렬 기능 |
| Must Have | 체크리스트 항목 선택 삭제하는 기능 | • 체크리스트 항목 여러 개를 한번에 삭제하는 기능 |
| Must Have | 추천 사유 / 필요성 코멘트 추가 | - 기내 수하물 반입 금지 정보 제공 포함
ex. 이 여행지의 여행객 75%가 챙겼어요, 비 올 때 필요해요 / 이건 안 챙겨도 돼요 |
| Must Have | 리마인더(여행 출발 D-N에 알림 받기)  | 여행 중 특정 물건이 필요한 날의 전날 저녁 혹은 당일 아침에 알림 (N : 근거를 가지고 정하기) |
| Nice to Have | 개인 준비물 체크리스트 프리셋 | • 개인화된 준비물을 프리셋으로 저장 및 불러오기
• 다른 여행지에서 사용했던 체크리스트 저장 및 불러오기 |
| Out of Scope | 짐 싸기 진행률 및 준비완료 배지 | ex. 10개 항목 중 8개 준비완료! |
| Out of Scope | 댓글 기능 | ex. 이 물건이 도움 되었어요 |

삭제율 집계는 활동(액티비티)를 통해 추가된 아이템에 대해서만 실행

삭제율 = 유효 삭제 건수 / 유효 노출 건수

유효 삭제 = 전체 삭제
- 카테고리 일괄 삭제
- 리스트 초기화·재생성에 의한 삭제
- 실행 취소 버튼을 통해 Undo된 삭제

유효 노출 = 해당 항목이 생성된 여행 수
- 해당 항목이 포함된 카테고리 일괄 삭제
- 삭제된 여행 일정에 해당 항목이 포함돼있는 경우
