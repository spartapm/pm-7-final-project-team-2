## 1. CHG-044 · 겹치는 날짜 확인 다이얼로그 (A-02)

QA: 기존 일정과 하루라도 겹치면 확인 다이얼로그.

- **반영.** 하루만 겹쳐도 「잠깐! 이미 선택된 날짜로 등록된 일정이 있습니다…」
- 달력 연타 시 범위가 풀리던 버그도 같이 고침.
- 재확인: 베트남 9/21이 있는 상태에서 다른 나라 9/21 선택 → 다이얼로그 노출.

## 2. CHG-054 · NEW 칩 (B-01)

QA: 한 번도 안 연 일정에 NEW가 떠야 하는데 「신규」로 뜸.

- **반영.** 뱃지 문구 `NEW`. 생성 직후 `seen: false`, 체크리스트를 열면 사라짐.
- 재확인: 온보딩으로 태국 일정 생성 → `NEW` / 「신규」 없음. 카드 오픈 후 뱃지 제거.

## 3. CHG-007 · 아이콘 버튼 크기·정렬 (B-01, C-01, C-02, E-01)

QA: 미트볼, 케밥, 인포, 하트, 편집, 삭제. 디자인 가이드.

- **반영.** 히트영역 44px, 아이콘 자체는 가이드 크기. 정보–하트 간격 16, 편집 연필–X 간격 24. 미트볼은 화면 오른쪽에서 24.

## 4. CHG-056 · 구분선 두께 (C-01)

QA: 아이템 리스트에 따라 구분선 두께가 다르게 보임.

- **반영.** 행 구분선 1px `#F2F2F2`, 좌우 28 inset. 행 높이가 달라도 선 두께는 고정.

## 5. CHG-055 · 체크·정보·하트 세로 중앙 (C-01)

QA: 코멘트 없는 아이템은 영역 안에서 세로 중앙. 코멘트 있으면 영역 자체가 커짐.

- **반영.** 기본 행 48, 코멘트 있으면 64. 아이콘은 `align-items: center`.

## 6. CHG-051 · 긴 아이템명 줄바꿈 (C-01)

QA: 아이템명이 영역을 벗어남.

- **반영.** `overflow-wrap: break-word`, `word-break: keep-all`. 말줄임 없음.

## 7. CHG-050 · 긴 카테고리명 줄바꿈 (C-01)

QA: 카테고리명이 영역을 벗어남.

- **반영.** 카테고리 타이틀도 동일하게 줄바꿈.

## 8. CHG-048 · 플로팅 카운터 색 (C-01)

QA: 하단 카운터 색이 디자인 명세와 다름.

- **반영.** 120×28, 흰 배경, Text 3, 하단 20. 스크롤 방향에 따라 숨김/노출은 기존 유지.

## 9. CHG-063 · 정보 안내 모달 (C-05)

QA: 「정보 안내」 타이틀·구분선·확인 버튼 삭제. 리스트에 chevron. 부가설명 회색 박스.

- **반영.** 타이틀/확인 없음. 링크 행 + chevron. `link_note`가 있을 때만 회색 박스.
- 재확인: 링크만 있는 아이템 → 타이틀·확인 없음, chevron 있음. 노트 없으면 회색 박스 없음 (맞음).

## 10. CHG-026 · D-01 30자 토스트

QA: 30자 넘어도 토스트가 안 뜸. (`maxLength` 때문에 31번째 글자가 안 들어감)

- **반영.** 31자에서 30자로 자르고 「최대 30자까지 입력할 수 있어요」. 한글 조합(IME) 대응.
- 재확인: 31자 입력 → 클램프 + 토스트.

## 11. CHG-025 · D-01 다이얼로그 UI

QA: 커서 위치 이상. 긴 글자 줄바꿈은 완료로 표시됨.

- **반영.** 빈 필드는 커서를 맨 앞(0)에. 입력 중에는 그대로. textarea 줄바꿈.

## 12. CHG-047 · 삭제율 높은 아이템 코멘트 (E-01)

QA: 편집 화면에서 과잉 짐싸기 코멘트 변경.

- **반영 (조건).** 70–79.9% 「10명 중 3명이 챙겼어요」, 80–89.9% 2명, 90%+ 1명.
- 카탈로그 아이템 + 라이브 삭제율(`/admin`에서 70% 이상)이 있어야 보임. 로컬 CSV만으로는 안 나옴.

## 13. CHG-058 · 연필로 수정 완료 불가 (E-02)

QA: 연필을 눌러도 수정 시작만 되고 완료가 안 됨. (blur와 클릭이 경합)

- **반영.** 연필 `mousedown`에서 `preventDefault`. 다시 누르면 저장. 빈 이름은 원래 이름으로 복구.
- 재확인: 커스텀 아이템 → 연필 → 수정 → 연필 클릭으로 저장.

## 14. CHG-057 · 연필 색 / X 숨김 (E-02)

QA: 수정 중 연필이 파란색으로 바뀌고 X는 사라져야 함.

- **반영.** 수정 중 연필 Primary, X 숨김.
- 재확인: 스트로크 `var(--primary)`, X 없음.

## 15. CHG-064 · 나만의 준비물 (F-01)

QA: 카테고리 삭제 시 연동 아이템까지 삭제. 추가 목록에 「나만의 준비물」. 새로고침으로 자동 추가 금지. 추가하면 빈 카테고리.

- **반영.** 삭제하면 진행 중 일정의 카테고리·카탈로그 아이템 제거. 추가하면 빈 카테고리 + 「모든 여행 일정에 담겨요」. 새로고침으로 안 생김.
- 새 일정을 만들 때 이미 있는 나만의 준비물은 체크리스트 맨 위에 같이 담김 (`82686ff`).
- 재확인: 추가 목록에 항목 있음. 빈 카테고리 + 힌트. 「아이템 추가」만 보임.

## 16. CHG-059 · G-01 정렬 (G-01)

QA: 아이콘, 텍스트 필드, 플러스 세로 중앙. 아이템 영역 크기.

- **반영.** 추가 행도 같은 row 높이·중앙 정렬.

## 17. CHG-034 · 미입력 시 + 비활성 (G-01)

QA: 텍스트 필드 비면 + 비활성화.

- **반영.** 빈 값·30자 초과는 `aria-disabled`, 클릭해도 추가 안 됨.
- 빈 값은 + 색 Primary 유지. 30자 넘으면 Text 3.

## 18. CHG-035 · G-01 30자 토스트

QA: 30자 넘어도 토스트가 안 뜸.

- **반영.** 30자를 넘는 순간, 그리고 그 상태에서 +/Enter 시 「최대 30자까지 입력할 수 있어요」.
- 재확인: 31자 → 토스트, + 비활성.

## 19. CHG-053 · 공유 링크가 다른 계정으로 열림 (ETC)

QA: 공유 링크를 번갈아 열면 이전 계정 홈이 남음. 쿠키/캐시 지우고 열면 정상.

- **반영.** 없는 계정은 빈 일정으로 덮어쓰지 않음. `/s/:id`는 `adoptAccount`로 통째로 교체. 예전 `chaeggyeo_*` 쿠키는 last-home 읽을 때 삭제 (`82686ff`).
- 재확인: `/s/accLocalA` → 일본만. `/s/accLocalB` → 미국만, 일본 없음.

## 20. CHG-049 · CSV를 Supabase에서 편집 (ETC)

QA: 제출 CSV가 웹 내장이 아니라 DB에 있어야 함. 상태가 작성필요.

- **반영 (조건).** 아이템·규칙·삭제율은 Supabase. `/admin`에서 수정. 시드 SQL/CSV는 이미 올라가 있음.
- 어드민에서 70% 데모를 넣어야 CHG-047 코멘트가 보임.
